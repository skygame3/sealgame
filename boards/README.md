# SEAL 보드 정의

각 보드는 `schema.json`의 구조와 `app/src/boards/validateBoard`의 그래프 규칙을 모두 만족해야 한다.

## 필드

- `id`: 보드의 영구 식별자. 소문자 짧은 이름을 사용한다.
- `name`: UI에 표시할 기본 이름. 번역 키는 i18n 태스크에서 별도로 관리한다.
- `version`: 보드 데이터 스키마 버전. 현재 `1`.
- `nodes`: 해상도와 무관한 `x`, `y` 좌표(각각 0~1)와 고유 `id`.
- `edges`: 무향 연결. 각 쌍은 사전순으로 작은 ID를 먼저 기록한다.
- `lockedNodes`: 게임 시작 시 잠긴 노드. 💎3으로만 개방할 수 있다.
- `keyNodes`: 동점 승부를 가르는 핵심 노드.

## 검증 규칙

- 모든 edge와 `lockedNodes`/`keyNodes`의 ID는 `nodes`에 있어야 한다.
- 그래프는 연결되어야 하며, 자기 연결과 중복 edge를 허용하지 않는다.
- 포획을 만들 수 있는 길이 2의 경로(노드 3개)가 최소 하나 필요하다.

새 JSON 보드는 추가 시 `validateBoard` 테스트를 통과해야 한다.

## MVP H 보드

`h.json`은 13개 노드, 14개 edge의 H형 기본 보드다. `x0`, `x1`은 잠긴 확장 노드이고
중앙 `c`는 핵심 노드다. 좌우 기둥과 중앙 다리의 연결은 여러 포획 경로를 제공한다.
